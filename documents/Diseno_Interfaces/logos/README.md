## Cómo se han preparado para la web

1. Se quitó el fondo blanco y se dejó transparente, conservando los bordes suaves.
2. Se recortó el margen vacío.
3. Se redujeron al tamaño necesario: la cabecera muestra el logo a 46 px de alto, así que el fichero tiene 112 px (el doble, para que se vea nítido en pantallas de alta densidad).
4. En la web se usa el formato **WebP**, que pesa aproximadamente la mitad que el PNG con la misma calidad.
5. Para el pie se creó una **versión clara**: el texto azul marino no se leía sobre el morado oscuro, así que la palabra «SABITECH» pasa a blanco y la «X» mantiene su degradado.

Resultado: de 571–703 KB por imagen a 8–11 KB en la web.
